# Santa's Workshop - Interactive Christmas App for Toddlers

A magical, interactive Christmas experience designed for children aged 3-5 years old. This app incorporates the Elf on the Shelf narrative with Christian values, focusing on positive behavior and the joy of Christmas.

## Features

### 🌟 My Nice List Stars
- Children earn stars for good deeds and positive behavior
- Focus on encouragement and kindness (sharing, helping, good manners)
- Positive reinforcement with Christian-friendly messages
- Stars are saved and accumulated over time
- **NO emphasis on "naughty list"** - only positive encouragement!

### 🎁 My Wish List
- Interactive buttons for common toy categories
- Kids can add wishes with help from a grown-up
- Santa-themed responses for each wish added
- Wishes are saved locally

### 🎅 Talk to Santa
- **Voice recognition** - kids can actually talk to Santa!
- Santa responds with encouraging, context-aware messages
- Christian values emphasized (kindness, love, family, gratitude)
- Text-to-speech so Santa "talks back"
- Fallback for browsers without voice support

### 🧝 Meet the Elves
- Four friendly elves with unique personalities:
  - **Jingle** - The Toy Maker
  - **Sparkle** - The Gift Wrapper
  - **Cookie** - The Baker
  - **Twinkle** - The Reindeer Keeper
- Click each elf to hear them talk!
- Voice responses with text-to-speech

### 🔍 Where's My Elf Today?
- Interactive Elf on the Shelf tracker
- Kids can guess where their elf is hiding
- Encourages observation and reinforces good behavior

## How to Use

### Opening the App
1. Open `index.html` in a web browser (Chrome or Edge recommended for voice features)
2. The app works best on tablets or computers with speakers
3. For voice features, you'll need to allow microphone access

### For Parents/Caregivers
- The app saves progress locally (stars and wishes)
- Voice recognition works best in Chrome and Edge browsers
- All content is family-friendly and age-appropriate
- No internet connection required after loading
- No data is sent anywhere - everything stays on your device

### Tips for Best Experience
- Use on a tablet for easy toddler interaction
- Enable sound for the full experience
- Help young children with the "Talk to Santa" feature
- Make it a daily ritual - check stars, talk to Santa, update wishes
- Use the Elf Tracker each morning to find the Elf on the Shelf

## Technical Details

### Technologies Used
- HTML5
- CSS3 with animations
- Vanilla JavaScript
- Web Speech API (voice recognition and text-to-speech)
- Web Audio API (sound effects)
- localStorage (saving progress)

### Browser Compatibility
- **Best experience**: Chrome, Edge (full voice support)
- **Good experience**: Firefox, Safari (limited voice support)
- **Mobile**: Works on tablets and phones
- No special plugins required

### Files
- `index.html` - Main application structure
- `styles.css` - All styling and animations
- `script.js` - Interactive functionality and voice features
